# Контур обучения `legal`

`legal` не меняет свои веса автоматически после переписки: это небезопасно для
юридической системы и приводит к накоплению ошибок. В эту папку попадают только
явно одобренные экспертом обезличенные примеры в `legal-approved.jsonl`.

Формат одной строки:

```json
{"messages":[{"role":"user","content":"..."},{"role":"assistant","content":"..."}],"approved_by":"reviewer","approved_at":"2026-08-15T00:00:00Z"}
```

Перед добавлением удаляйте персональные данные, коммерческую тайну и реквизиты
дел. Накопленный набор следует проверять, разделять на train/eval и только затем
дообучать отдельный адаптер (LoRA) на совместимом GPU. Исходный `legal` всегда
сохраняется как откатная версия.
