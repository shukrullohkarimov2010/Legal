# Локальные модели `legal`, `legal-strong` и `legal-fast`

`legal-strong` — текущая модель по умолчанию для анализа договоров. Она
использует локальную `qwen3:8b`, строгие правила цитирования и RAG с законами
Республики Таджикистан. `legal` остаётся прежним более лёгким профилем на базе
`llama3.1:8b`.

Для чата по умолчанию используется `legal-fast` на базе локальной `phi3`: он
быстрее отвечает потоково и получает только краткий релевантный RAG-контекст.
Анализ договоров по-прежнему использует более тщательный `legal-strong`.

Создать или обновить профиль:

```powershell
ollama create legal-strong -f deployment/Modelfile.legal-strong
```

Проверить:

```powershell
ollama run legal-strong "Назови правила точного цитирования норм права"
```

Затем перезапустите `python/app.py`. Для анализа важнее поддерживать актуальную
RAG-базу законов, чем автоматически менять веса модели. Обучающие примеры и
правила их отбора находятся в `python/training_data/README.md`.

`legal-strong` не является и не может стать локальной копией GPT-5.5: GPT-5.5 —
облачная модель OpenAI, а локальная `legal` использует установленную на ноутбуке
открытую базовую модель. Качество юридических ответов дополнительно обеспечивают
RAG и проверка источников.
